# Изображения и шрифты

Все семь интерьерных изображений созданы специально для этого демонстрационного проекта инструментом OpenAI image generation, 3 ноября 2026 года. Это синтетические иллюстрации, а не фотографии реальных товаров, помещений или компании. Изображения Unsplash/Pexels не использовались. Во время работы сайта обращения к внешним источникам изображений нет.

| Файл | Содержание | Использование |
| --- | --- | --- |
| `public/images/living.webp` | Кремовый диван, ореховый столик, тёплая гостиная | Hero, Koltuk Takımları, Milano, галерея |
| `public/images/corner.webp` | Угловой диван | Köşe Koltuklar, Luna |
| `public/images/bedroom.webp` | Спальня с мягким изголовьем | Yatak Odası, Verona, галерея |
| `public/images/dining.webp` | Ореховый стол и мягкие стулья | Yemek Odası, Masa ve Sandalyeler, Aura, Mira, галерея |
| `public/images/tv.webp` | ТВ-зона с ореховой консолью | TV Üniteleri, Nova |
| `public/images/chair.webp` | Светлое кресло с деревянными деталями | Siena, Hakkımızda |
| `public/images/table.webp` | Круглый ореховый журнальный столик | Petra, галерея |

Изображения оптимизированы в WebP до ширины 1440 px, суммарно около 1.8 MB. Изначальные PNG не входят в исходники и production-сборку.

Manrope Variable и Cormorant Garamond поставляются локально через пакеты Fontsource. Лицензия SIL Open Font License 1.1; оригинальные лицензии доступны в соответствующих npm-пакетах. Турецкий набор символов обеспечен Latin Extended. Lucide React — ISC.
